# Data

Raw data files are not included in this repository (third-party license restrictions).

- Price, volume, and risk-free rate data are downloaded automatically the first time you run the notebook (via `yfinance`).
- ESG scores: download "S&P 500 ESG Risk Ratings" from Kaggle and save it in this folder as `esg_kaggle.csv`.
